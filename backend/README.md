# Backend Configurations

This is the backend of the project, and serves is with Node.js and Flask for Python. In addtion to the Frontend, the backend is also hosted on Heroku. The backend is responsible for the following:

- Handling the requests from the frontend
- Processing the data
- Sending the data back to the frontend
- Performing machine learning tasks: such as training the model, making predictions, etc.

## Node.js

The backend is built using Node.js, and Flask consisting of the following packages:

- Express.js: A web application framework for Node.js
- Axios: A promise-based HTTP client for the browser and Node.js
- Cors: A Node.js package for providing a Connect/Express middleware that can be used to enable CORS with various options
- Nodemon: A tool that helps develop node.js based applications by automatically restarting the node application when file changes in the directory are detected

## Flask

The backend is built using Flask, consisting of the following packages:

- Flask: A micro web framework written in Python
- Flask-Cors: A Flask extension for handling Cross Origin Resource Sharing (CORS), making cross-origin AJAX possible
- Flask-RESTful: An extension for Flask that adds support for quickly building REST APIs
- Flask-RESTful-Swagger: An extension for Flask-RESTful which adds support for generating Swagger documentation

## Machine Learning

The backend is responsible for performing machine learning tasks, such as training the model, making predictions, etc. The machine learning model is built using the following packages:

- Scikit-learn: A simple and efficient tools for data mining and data analysis
- Pandas: A fast, powerful, flexible and easy to use open source data analysis and data manipulation library built on top of the Python programming language
- Numpy: A fundamental package for scientific computing with Python
- Models: (Models will be relaed and assigned regarding tasks and requirements)

## Deployment

The backend is deployed on Heroku, a cloud platform as a service (PaaS) supporting several programming languages. The backend is deployed using the following steps:

1. Create a new app on Heroku
2. Connect the app to the GitHub repository
3. Deploy the app

## Testing

The backend is tested using Postman, a collaboration platform for API development. The backend is tested using the following steps:

1. Install Postman
2. Create a new request
3. Send the request
4. Verify the response

## Documentation

The backend is documented using Swagger, an open-source software framework backed by a large ecosystem of tools that helps developers design, build, document, and consume RESTful web services. The backend is documented using the following steps:

1. Install Flask-RESTful-Swagger
2. Add Swagger documentation

## Conclusion

The backend is an essential part of the project, and serves as the bridge between the frontend and the machine learning model. The backend is built using Node.js and Flask, and is responsible for handling the requests from the frontend, processing the data, sending the data back to the frontend, and performing machine learning tasks. The backend is deployed on Heroku, and is tested using Postman. The backend is documented using Swagger, and is an essential part of the project.
